# Package index

## Event Functions

Functions for extracting complete event information

- [`get_event()`](https://justinjtownsend.github.io/skiresultsR/reference/get_event.md)
  : Extract all event information from an HTML file
- [`get_event_dtls()`](https://justinjtownsend.github.io/skiresultsR/reference/get_event_dtls.md)
  : Extract event details from an HTML file
- [`get_event_summary()`](https://justinjtownsend.github.io/skiresultsR/reference/get_event_summary.md)
  : Extract event metadata from an HTML file

## Race Functions

Functions for extracting race data and results

- [`get_races()`](https://justinjtownsend.github.io/skiresultsR/reference/get_races.md)
  : Extract all race tables from an event HTML file
- [`get_race()`](https://justinjtownsend.github.io/skiresultsR/reference/get_race.md)
  : Extract a specific race table by race ID from an event HTML file
- [`get_race_types()`](https://justinjtownsend.github.io/skiresultsR/reference/get_race_types.md)
  : Extract race types and event information from an HTML file

## Data Extraction Functions

Functions for extracting specific data types from races

- [`get_racers()`](https://justinjtownsend.github.io/skiresultsR/reference/get_racers.md)
  : Extract all registered racers from an event HTML file
- [`get_points()`](https://justinjtownsend.github.io/skiresultsR/reference/get_points.md)
  : Extract points data for a specific race
- [`get_clubs()`](https://justinjtownsend.github.io/skiresultsR/reference/get_clubs.md)
  : Extract all clubs from an event HTML file
